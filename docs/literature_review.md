# Hybrid TPA-Agent: 相關研究文獻、監管數據與實證基礎

本文件彙整專題所引用之最新權威學術研究、監管機構（FINRA）數據與金融微結構實證案例，作為本系統各層設計決策（Design Decisions）、研究缺口（Research Gap）與實驗驗證之論證依據。

## 1. 核心實證數據：短線交易與當沖之系統性風險

| 實證項目 | 關鍵數據 / 官方規範 | 專題論證用途與對應模組 | 文獻來源 |
| :--- | :--- | :--- | :--- |
| **巴西期貨當沖實證研究** | 追蹤 1,551 位持續交易逾 300 天的個人當沖客：<br>• **97% 最終虧損**<br>• 僅 1.1% 年化所得超過巴西最低工資<br>• 僅 0.5% 超過銀行櫃員起薪<br>• 未發現「交易越久越會獲利」之學習效應 | 證明散戶短線劣勢並非「資訊不足」或「多看指標」即可改善，而是高頻決策與心理偏誤的系統性結果。系統定位為「決策輔助與風控優先」，非宣稱保證獲利。 | [Chague et al., SSRN 2019 / Econ W.P.](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=3423101) |
| **FINRA Rule 2270 當沖風險揭露** | FINRA 明確指出：<br>• 當沖風險極高，極易損失全部投入資金<br>• 槓桿與放空可能導致超出初始本金之損失<br>• 系統故障、API 中斷、流動性不足與高頻交易成本皆會放大實質風險 | 確立系統必須內建**硬停損（Hard Stop-Loss）**、**流動性與 API 異常降級機制**、**槓桿上限**與**摩擦成本敏感性分析**。 | [FINRA Rule 2270](https://www.finra.org/rules-guidance/rulebooks/finra-rules/2270) |
| **FINRA 2024 當沖規則檢討** | 即使具備深厚市場知識之經驗交易者，亦常遭遇嚴重且非預期的鉅額虧損；美國參議院報告亦高度關切散戶虧損證據。 | 用於 Introduction 問題陳述：專業知識不足非唯一主因，執行紀律與風險治理才是關鍵瓶頸。 | [FINRA Regulatory Notice 24-13](https://www.finra.org/rules-guidance/notices/24-13) |
| **高額交易摩擦成本** | FINRA 實例測算：若每筆交易成本（手續費+價差）為 $16 美元、每日 29 筆交易，一年需約 $111,360 美元毛利才能「打平」手續費。 | 強化「高頻訊號不等於高期望值」之論點；系統回測必須納入手續費、滑點與價差，並做 Walk-forward 檢驗。 | [FINRA Rule 2270](https://www.finra.org/rules-guidance/rulebooks/finra-rules/2270) |

## 2. 金融 LLM Agent 與混合架構之最新文獻 (2025–2026)

### 2.1 數值與空間計算解耦 (Decoupling)
- **Agentic Trading: When LLM Agents Meet Financial Markets (arXiv:2605.19337)**:
  - 將金融 LLM Agent 定義為「感知、記憶、推理、執行」管線。
  - **核心警示**：LLM 的金融幻覺（Hallucination）具有致命實質風險。文字推論的錯誤數值或空間判斷，會透過 Tool-calling 傳播為實際錯誤下單、部位超載或連鎖停損。
  - **本系統對策**：Hybrid TPA-Agent 將 Swing High/Low、供需區邊界座標、ATR、停損點及期望值計算交由 100% 確定性 Python 程式與 ML 負責；LLM 僅接收經過驗證的結構化 JSON 進行情境推理與敘事審查。

### 2.2 檢索增強生成 (RAG) 與多 Agent 專業化分工
- **RAG-enhanced Multi-Agent Framework for Quantitative Finance (ACM 2026, 10.1145/3788149.3788249)**:
  - 結合策展知識庫之 RAG 多 Agent 系統，在模擬股票市場達成 +3.25% 報酬，顯著優於單 Agent (+2.15%) 及無 RAG 之多 Agent (+1.82%)，且最大單筆損失與回撤頻率大幅下降。
  - **本系統應用**：以 Price Action 領域知識庫（S/R Flip, 突破後回測確認, 假突破特徵）增強 LLM 推理，大幅降低非結構化推論之幻覺。

### 2.3 長期回測與防過度擬合批判
- **FINSABER: 2004–2024 逾 100 檔標的長週期回測 (ACM 2025/2026, 10.1145/3770854.3785702)**:
  - 發現過去諸多宣稱「LLM 擇時勝率超群」的研究，在擴大到多標的、長週期與納入交易成本後，超額報酬顯著衰退。
  - **本系統對策**：不採用單一標的、單一週期進行回測；嚴格實施時間序列 Walk-forward Validation，禁止隨機切分（Random Split）避免未來資料洩漏（Data Leakage）。

## 3. 典型市場事件與風控安全降級對照

| 市場真實歷史事件 | 暴跌與市場失衡痛點 | Hybrid TPA-Agent 防禦與降級機制 |
| :--- | :--- | :--- |
| **2020 年 3 月 COVID-19 崩跌** | 波動率暴增、買賣價差與流動性急遽惡化，固定點數停損與靜態指標完全失效。 | **ATR 動態風控** + **波動度 Regime 濾網** + **槓桿自動折半**。 |
| **2021 年 GameStop 迷因股暴動** | 社群非理性狂熱、軋空行情導致技術面訊號完全失真。 | **異常成交量 Z-score 偵測** + **主動輸出 NO_TRADE 保護**。 |
| **2022 年加密貨幣連環去槓桿** | 流動性踩踏、連環爆倉，市價單停損遭遇嚴重滑點。 | **預掛限價/止損委託** + **單日最大風險金額限制 (Max Daily Loss Limit)**。 |
| **交易所 / 券商 API 中斷事件** | 網路中斷或 API Rate Limit 導致無法即時停損或成交確認。 | **Level 1~3 安全降級協議**：心跳丟失即啟動保護性撤單或硬停損。 |
